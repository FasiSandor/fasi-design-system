# FS Design System – Style Guide

## Alapelv

Az FS arculat appfüggetlen. A márka **FÁSI SÁNDOR**, az adott alkalmazás vagy dokumentum neve külön címként jelenik meg.

## UI-karakter

- világos, tiszta főfelület
- fényes, telített CTA színek
- sötétkék/electric-blue fejléc
- cyan fény és finom glow
- kerekített kártyák
- mobil-first
- pasztell és bézs kerülendő

## Dokumentumok

### Fejléccel / branded

Saját riportokhoz, portfólióhoz, bemutatókhoz és külső dokumentumokhoz.

Tartalmazza:
- FS jelet
- FÁSI SÁNDOR feliratot
- „digitális rendszerek” alcímet
- navy/electric-blue/cyan fejlécet

### Fejléc nélkül / school

Iskolai belső nyomtatáshoz.

- nincs személyes FS branding
- fehér lap
- egyszerű cím
- szürke táblázatfejléc
- takarékosabb nyomtatás

## Nyomtatási elv

Az app UI soha nem kerül közvetlenül papírra. A nyomtatási komponens külön A4 dokumentumnézetet készít.

Csak a tényleges adatokat tartalmazó sorokat kell nyomtatni.

## Használati szabály

Meglévő, már elfogadott app UI-ját nem kell automatikusan teljesen áttervezni. Új appnál ez az alapértelmezett arculat; meglévő appnál fokozatosan, kért módosításoknál vezetjük be.
